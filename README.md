# 馋了吗 - 冲动外卖冷静器

> 一个具有真实外卖点餐手感、但不会扣款或配送的消费决策原型。

当前 `codex/chanlema-v0.2` 版本在原有外卖界面基础上，补齐了规格价格、起送门槛、配送费、满减、订单持久化，以及“替代餐 → 净节省金额/净热量差”的核心闭环。

## 📁 文件结构

```

├── index.html           # 首页（地址、搜索、分类、商家列表）
```

## 🚀 快速开始

### 方式1：直接打开首页
1. 用浏览器打开 `index.html`
2. 点击商家卡片进入商家详情
3. 点击菜品的 `+` 按钮添加到购物车
4. 点击底部 `去结算` 按钮进入购物车页面
5. 点击 `模拟付款` 后选择替代餐，再查看净节省和净热量差

### 方式2：用 VS Code Live Server
1. 在 VS Code 中打开 `外卖` 文件夹
2. 右键选择 `Open with Live Server`
3. 自动打开 http://localhost:5500/index.html

### 方式3：用 Python 启动本地服务器
```bash
# Python 3
cd path/to/meituan-takeout-demo
python -m http.server 8000

# 然后访问 http://localhost:8000
```

## 🎯 功能特点

### 完整的点餐流程
- 搜索商家 → 查看详情 → 选择菜品 → 管理规格 → 购物车结算 → 虚拟下单

### 外卖风格UI
- 参考常见外卖产品的点餐信息结构
- 颜色、字体、间距针对手机页面优化

- 不调用真实支付接口

- 3个商家（咖啡、小吃、火锅）
- 多种菜品和规格选项
- 真实的配送费、起送价等

## 🐛 已知限制

- 商家、菜单、地址均为演示数据，不代表实时营业信息
- 优惠券选择仍为演示提示；系统分享能力因浏览器而异
- 地址管理仅为展示，无法编辑
- 没有真实的评价和用户系统
- 数据存储在本地，不会同步到其他设备或浏览器
